## Car Availability Checker

**Car Availability Checker** is a lightweight web application that helps a single car owner manage vehicle availability through an interactive calendar. The owner can select a date range to instantly check which cars are available or already booked, preventing scheduling conflicts and double bookings. Built with **HTML, CSS, and JavaScript**, the application features a clean, responsive interface and simple booking management without requiring a database or user authentication, making it ideal for personal fleet management and as a portfolio project.
